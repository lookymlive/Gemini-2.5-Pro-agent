# 🤖 Gemini AI Video Upload App

A Node.js application that uses Google's Gemini AI to help create a video upload and storage application.

## 🚀 Features

- Integration with Google's Gemini AI
- Video upload functionality
- Modern Node.js architecture
- Easy to use API

## 🛠️ Prerequisites

- Windows OS
- Node.js (v14 or higher)
- npm (comes with Node.js)
- Google Gemini API Key

## 📦 Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/yourusername/gemini-video-app.git
   cd gemini-video-app
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Set up environment variables**:

   - Create a `.env` file in the root directory and add your API key:
  
     ```env
     GEMINI_API_KEY=your_actual_api_key_here
     ```

## 🎯 Usage

1. **Start the application**:

   ```bash
   npm start
   ```

2. **Functionality**:
   - The application will use Gemini AI to generate content based on the input provided in the `agent.js` file.

## 🔒 Environment Variables

- Ensure your `.env` file contains the following:

  ```env
  GEMINI_API_KEY=your_actual_api_key_here
  ```
