# 🤖 Gemini AI Video Upload App

A Node.js application that uses Google's Gemini AI to help create a video upload and storage application.

## 🚀 Features

- Integration with Google's Gemini AI
- Video upload functionality
- Modern Node.js architecture
- Easy to use API

## 🛠️ Prerequisites

- Node.js (v14 or higher)
- npm (comes with Node.js)
- Google Gemini API Key

## 📦 Installation

1.Clone the repository:

```bash
git clone https://github.com
cd gemini-video-app
```

2.Install dependencies:

```bash
npm install
```

3.Create a `.env` file in the root directory and add your API key:

```env
GEMINI_API_KEY=your_api_key_here
```

## 🎯 Usage

4.Start the application:

```bash
npm start
```

1. The application will use Gemini AI to help you create your video upload app.

## 🔒 Environment Variables

Create a `.env` file with the following variables:

```env
GEMINI_API_KEY=your_api_key_here
```
